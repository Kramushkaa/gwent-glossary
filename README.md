# Глоссарий GWENT

Статическая страница со словарём терминов, механик, архетипов и жаргона
карточной игры GWENT. Собрано из вики-страниц сообщества
[Claymore](https://vk.com/club154778374) во «ВКонтакте».

Одна страница, оглавление в сайдбаре, живой поиск по терминам и определениям,
тёмная и светлая темы. Без фреймворков, сборщиков и зависимостей — обычные
HTML, CSS и JavaScript, поэтому сайт работает на GitHub Pages «как есть».

## Что внутри

```
index.html            готовая страница (генерируется, руками не правим)
assets/style.css      оформление
assets/app.js         поиск, оглавление, переключение темы
data/glossary.json    те же данные в машиночитаемом виде
raw/page_1..13.txt    исходные вики-страницы ВКонтакте, как они были сохранены
build.py              сборка index.html и data/glossary.json из raw/
```

## Пересборка

Нужен только Python 3.9+ (сторонних пакетов нет):

```bash
python build.py
```

Скрипт разбирает вики-разметку ВКонтакте, склеивает 13 страниц в один список
терминов, разрешает внутренние ссылки между терминами и перезаписывает
`index.html` и `data/glossary.json`. Если какая-то ссылка не находится, сборка
напечатает её в консоли, а в HTML она попадёт помеченной пунктиром.

## Как опубликовать на GitHub Pages

```bash
git init
git add .
git commit -m "Глоссарий GWENT"
git branch -M main
git remote add origin https://github.com/<логин>/<репозиторий>.git
git push -u origin main
```

Затем в репозитории: **Settings → Pages → Build and deployment →
Source: Deploy from a branch → Branch: `main`, папка `/ (root)` → Save**.
Через минуту страница будет доступна по адресу
`https://<логин>.github.io/<репозиторий>/`.

## Иллюстрации

В исходных вики-страницах было 18 картинок (логотипы дополнений, символы
статусов). Они лежали в закрытом хранилище фотографий ВКонтакте и без
авторизации не отдаются, поэтому сейчас на их месте остались только подписи.

Если картинки нужны, положите файл в `assets/img/` под именем, совпадающим с
номером фотографии из исходной разметки (например,
`raw/page_1.txt` содержит `[[photo488968308_457263731|...]]` — файл должен
называться `assets/img/488968308_457263731.png`, подойдёт `.jpg`, `.jpeg`,
`.webp`, `.gif` или `.svg`), и пересоберите страницу. Сборщик подставит
изображение вместо подписи автоматически.

## О данных

Исходные тексты сохранены дословно, включая орфографию и пунктуацию авторов:
заметные опечатки вроде «Хартстоун» → «Heartstone» или «6 фракций» при
перечислении пяти не исправлялись. Термины без определения («Схватка»,
«Хищник», «Миррор», «Монеты», «ОБТ», «Гвинтфинити») остались в глоссарии с
пометкой, что статья не заполнена.

Материал перенесён в открытый вид, потому что раздел вики-страниц ВКонтакте
прекращает работу 4 декабря 2025 года.
